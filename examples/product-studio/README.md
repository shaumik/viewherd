# Forma Studio

Turn a product photo into a launch campaign.

Create two directions, compare them, adjust the copy and colors, then download the winning design as SVG or PNG. You can also upload your own product photo.

Run `npm run example` from the repository root and open http://localhost:4317.

The sample assistant runs a scripted workflow through Viewherd’s SDK. It creates, edits, and closes real panels. Your edits and the downloads are real; no AI model is connected.

The sample headphones and brand are fictional. The example uses the same panel actions available to an agent through the API or MCP.
