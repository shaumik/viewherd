    The Viewherd SDK

    Your app. Agent addressable.

    Relay’s inbox, tickets, customer context, and composer are custom panels. The SDK manages the workspace and routes their actions.

    01

    Register your panels

    Keep your UI and business logic. Define each panel’s data and named actions on your server.

    02

    Mount the workspace

    Your renderers plug into a small DOM shell. Tabs, splits, focus, and panel lifecycle come from Viewherd.

    03

    Connect your agent

    HTTP and MCP share one command contract. SSE keeps every connected UI in sync.

    import { createClient } from '@viewherd/client';
import { mountWorkspace } from '@viewherd/dom';

const client = createClient({
  baseUrl: '/webdr',
  sessionId: 'support-desk'
});

mountWorkspace(element, { client, panels });

await client.call('panel.action', {
  paneId: ticketPane.id,
  action: 'prepareReply',
  args: {}
});
    A real reference app
